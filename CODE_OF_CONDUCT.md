# Code of Conduct

I want discussions and contributions in this repository to remain professional, direct, and constructive.

- Discuss code and evidence, not personal characteristics.
- Assume good intent while remaining precise about technical risks.
- Do not publish private data, credentials, or vulnerability details.
- Respect licensing and authorship.
- Harassment, threats, discrimination, and sustained disruptive behavior are not accepted.

Repository access or participation may be limited when these boundaries are ignored.
